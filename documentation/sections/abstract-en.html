Abstract

Behavioral Interoperability Testing Ontology (BITO) provides an ontology-based representation layer for behavioral interoperability testing. It supports the representation of expected scenario behavior, behavioral constraints, observed execution evidence, trace evidence, validation results, and interoperability verdicts. BITO connects what is expected from an implementation under test with the evidence observed during execution, enabling behavioral requirements and assessment results to be represented explicitly and consistently. The ontology is designed as a lightweight behavioral layer that complements reused domain ontologies. Existing concepts are reused where their semantics match the intended modelling purpose, while BITO-specific concepts are introduced where additional behavioral-testing semantics are required. The current version includes representative validation instances for three Flexible Start scenarios to demonstrate the modelling approach.
